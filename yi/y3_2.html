一、工作環境（採光照明、通道）

職業安全衛生法 第6條第1項第14款：雇主應防止未採取充足通風、採光、照明、保溫或防濕等引起之危害。

採光照明 — 職業安全衛生設施規則第313條

雇主對於勞工工作場所之採光照明，應依下列規定辦理：

  1. 各工作場所須有充分之光線（處理感光材料、坑內及其他特殊作業之工作場所不在此限）
  2. 光線應分佈均勻，明暗比並應適當
  3. 應避免光線之刺目、眩耀現象
  4. 各工作場所之窗面面積比率不得小於室內地面面積十分之一
  5. 採光以自然採光為原則，但必要時得使用窗簾或遮光物
  6. 作業場所面積過大、夜間或氣候因素自然採光不足時，可用人工照明依表補足
  7. 燈盞裝置應採用玻璃燈罩及日光燈為原則，燈泡須完全包蔽於玻璃罩中
  8. 窗面及照明器具之透光部份，均須保持清潔

職業安全衛生設施規則第314條：雇主對於下列場所之照明設備，應保持其適當照明，遇有損壞，應即修復：階梯、升降機及出入口／電氣機械器具操作部份／高壓電氣、配電盤處／高度2公尺以上之勞工作業場所／堆積或拆卸作業場所／修護鋼軌或行於軌道上之車輛更換連接作業場所／其他易因光線不足引起勞工災害之場所。

通道 — 職業安全衛生設施規則第21條

雇主對於勞工工作場所之通道、地板、階梯、坡道、工作台或其他勞工踩踏場所，應保持不致使勞工跌倒、滑倒、踩傷、滾落等之安全狀態，或採取必要之預防措施。

常見通道危害：路面積水濕滑、路面走道過窄碰撞跌倒、走道堆積物過多絆倒（含樓梯轉角堆積物）、逃生通道堆積物過多致緊急時無法逃生。

職業安全衛生設施規則第30條：雇主對於工作場所出入口、樓梯、通道、安全門、安全梯等，應依第313條規定設置適當之採光或照明，必要時應設置緊急照明系統。
職業安全衛生設施規則第31條：雇主對於室內工作場所，應依下列規定設置足夠勞工使用之通道：
  1. 應有適應其用途之寬度，主要人行道不得小於1公尺
  2. 各機械間或其他設備間通道不得小於80公分
  3. 自路面起算2公尺高度範圍內，不得有障礙物（因工作必要經防護措施者不在此限）
  4. 主要人行道及有關安全門、安全梯應有明顯標示
命題角度提醒：窗面面積十分之一、人行道1公尺、機械間通道80公分、2公尺高度以上淨空這幾個數字最常被出成刪去題或數字代換題。

三、機械設備安全

機械設備安全之目的

  1. 保護人員安全
  2. 維護正常作業
  3. 減少財產損失

良好機械防護物應具備之條件

  1. 符合職業安全衛生法令及國家標準規定
  2. 應為機器上之一項永久設備或裝置
  3. 防護物須堅固耐用，且不易著火、腐蝕
  4. 能提供最大之防護功能，防止身體接觸而傷害
  5. 不會因設置機械防護物而減低機器本體之強度
  6. 本身不會造成新的傷害之危險
  7. 不致妨礙生產或造成操作不便
  8. 容易保養、上油、檢查、調整及修理
機械職災概況（統計重點）：機械製造修配業失能職災類型中，「刺擦割傷」佔比最高（45.9%），其次為墜落滾落、物體飛落、被撞、接觸有害物、跌落、感電（3.1%）等；就整體職業傷病職災類型而言，「被夾被捲」為第一名，其次為被刺割擦傷、墜落滾落、跌落、物體飛落。

機械之危害源 — 常見機械運動及動作種類

  1. 轉動、直線（含往復）運動（基本運動）
  2. 動作捲入點
  3. 切割動作
  4. 擠夾、衝擊
  5. 衝、截、彎等動作
  6. 高速迴轉體引起之飛擊動作

機械之危害發生位置：作業區、動力傳動區、移動區。

應採防護措施型式考量：不易拆卸及破壞、不影響操作、有效隔離觸及、防止異物掉入。

常見之安全防護：護圍、護罩；具連鎖性能之安全門；安全停止裝置（緊急按鈕、拉桿及安全門）。

職業安全衛生設施規則第45條、第48條（緊急制動裝置）：原動機、動力轉動機械、動力傳動裝置，具有顯著危險者，應有明顯標誌之緊急制動裝置，設於適當位置以便災害發生之際可立即使用停止機械運轉（各作業面），具遮斷動力＋制動功能，並有明顯標示（文字標示＋紅色）。

送菜升降梯之五大安全裝置：①緊急停止 ②極限開關（上極限、下極限） ③馬達保護器 ④保險絲 ⑤鋼索耐重噸數。

職業安全衛生法 第6條第1項（節錄）：雇主對機械設備器具、爆炸性發火性物質、電熱等能、採石採掘裝卸搬運堆積採伐作業、墜落物體飛落崩塌、高壓氣體…等14款事項應有符合規定之必要安全衛生設備及措施（末端管理，處罰雇主）。
職業安全衛生法 第5條第2項：機械、設備、器具、原料、材料等物件之設計、製造或輸入者，及工程之設計或施工者，應於設計、製造、輸入或施工規劃階段實施風險評估，致力防止此等物件於使用或工程施工時發生職業災害（源頭管理，管制設計/製造/輸入端）。
末端管理 vs 源頭管理：舊法（勞工安全衛生法）著重末端管理（使用端／雇主）；現行職業安全衛生法著重源頭管理（源頭端／風險產生者，即設計、製造、輸入者）。購買安全設備時應認明安全標示與驗證合格標章（TS標章：勞動部職安署安全標準認證；BSMI標章：經濟部標準檢驗局認證）。

四、感電危害預防

感電在各種職災類型中佔第二位，且有逐漸升高趨勢。

災害發生率與作業經歷之浴盆曲線關係

  • 新進勞工：經驗不足、欠缺教育訓練 → 對策：給予教育訓練與現場監督指導
  • 資深勞工：過度自信、不安全行為 → 對策：再教育訓練、加強自主管理、落實作業前檢點及自動檢查

人體電阻與感電電流

人體電阻＝皮膚電阻＋內部組織電阻（內部組織電阻變化不大，視為常數）。皮膚電阻隨接觸電壓上升而下降、隨皮膚濕度上升而下降。增加人體電阻值可減少感電電流值（保持皮膚乾燥為直接方式；藉助防護具增加接觸間電阻值為間接方式）。

致命電流：心室痙攣、血液循環停止，足以致命（依感電電流與人體生理反應表，交流60Hz男子致命電流約1300mA、女子約1300mA之對應數值，電擊時間越短需要電流越大）。

職業安全衛生設施規則第264條（專任電氣技術人員設置）：
  • 低壓：600伏特以下供電，且契約容量達50瓩以上之工廠或供公眾使用之建築物，應置初級電氣技術人員
  • 高壓：超過600伏特至22,800伏特供電之用電場所，應置中級電氣技術人員
  • 特高壓：超過22,800伏特供電之用電場所，應置高級電氣技術人員
用電場所及專任電氣技術人員管理規則 第6條（各級資格）：
  • 高級電氣技術人員：具電機技師資格，或室內配線／工業配線／配電線路裝修／用電設備檢驗／變壓器裝修職類甲級技術士技能檢定合格
  • 中級電氣技術人員：甲種電匠考驗合格，或前述職類乙級技術士技能檢定合格
  • 初級電氣技術人員：乙種電匠考驗合格，或前述職類丙級技術士技能檢定合格
職業安全衛生設施規則第241條（帶電部分之防護）：雇主對於電氣機具之帶電部分，如勞工作業中或通行時有因接觸或接近致發生感電之虞者，應設防止感電之護圍或絕緣被覆（電氣機具設於配電室等被區隔場所且禁止無關人員進入者不在此限）。
職業安全衛生設施規則第242條（電燈之護罩）：連接於移動電線之攜帶型電燈，或連接於臨時配線、移動電線之架空懸垂電燈等，應設置合乎規定之護罩：①燈座露出帶電部分應為手指不易接觸之構造 ②應使用不易變形或破損之材料。
職業安全衛生設施規則第243條（漏電斷路器）：雇主為避免漏電而發生感電危害，應於下列狀況之連接電路上設置具高敏感度、高速型漏電斷路器：
  1. 使用對地電壓在150伏特以上移動式或攜帶式電動機具
  2. 於含水或導電度高之潮濕場所、金屬板上或鋼架上等導電性良好場所使用移動式或攜帶式電動機具
  3. 於建築或工程作業使用之臨時用電設備

作業安全步驟

電氣箱內應設中隔板、電線應有絕緣包覆；作業前應切斷電源、電箱上掛牌標示（停電作業中、禁止送電）、以驗電筆或三用電表確認無電；並實施門禁管制設置警示措施避免無關人員接近。

命題角度提醒：電氣技術人員設置門檻（低壓600V＋50瓩、高壓22,800V以下、特高壓超過22,800V）、漏電斷路器150V門檻、24V安全電壓、接地電阻值數字，是感電章節的高頻考點。

五、高處作業危害預防

工作場所重大職災中，墜落約佔全部災害49%。高處作業之常用工具為移動梯與合梯，錯誤使用（如站立頂板作業、置於移動車輛載貨台上、設於高低差不平穩處所）皆不合規定。

職業安全衛生設施規則第229條（移動梯）：雇主對於使用之移動梯，應符合下列規定：
  1. 具有堅固之構造
  2. 其材質不得有顯著之損傷、腐蝕等現象
  3. 寬度應在30公分以上
  4. 應採取防止滑溜或其他防止轉動之必要措施

移動梯構造重點數字

  • 最小柱間寬度在30公分以上（梯柱間之間距）
  • 踏板應等間隔設置，垂直間隔以30～35公分為宜
  • 梯柱和地板建議在75度以內使用（4:1之比）
  • 移動梯上端應凸出板面60～100公分
  • 移動梯不得搭接使用
  • 應設置防止翻轉傾倒之設備，梯腳採取防止滑溜設備
  • 在鬆軟泥地上使用時，支柱底腳下應墊平板
  • 作業人員應以面對爬梯之方式上下，不得二人以上同時攀登，手腳應維持三點以上接觸，嚴禁手持工具或物料攀爬
職業安全衛生設施規則第230條（合梯）：雇主對於使用之合梯，應符合下列規定：
  1. 具有堅固之構造
  2. 其材質不得有顯著之損傷、腐蝕等
  3. 梯腳與地面之角度應在75度以內，且兩梯腳間有金屬等硬質繫材扣牢，腳部有防滑絕緣腳座套
  4. 有安全之防滑梯面
雇主不得使勞工以合梯當作二工作面之上下設備使用，並應禁止勞工站立於頂板作業。

六、人因性危害／過勞／職場暴力預防

人因工程與常見肌肉骨骼疾病

人因工程探討人與機器設備、環境之間交互作用的關係，透過設計適當調整，避免設計不良對工作者造成傷害，如：椎間盤突出、下背痛、膝關節半月狀軟骨病變、腕道症候群。

造成骨骼肌肉傷害的五大成因：不良的姿勢、過度施力、高重複動作、長時間暴露、震動與低溫。

常見行業人因危害範例：餐飲業（彎腰搬重、低頭剁菜、久蹲急站）；汽車修理業（彎腰卸胎、輪胎定磅、底盤維修）。

肌肉骨骼疾病預防方法：適當運動（伸展操、慢走）避免體重過重；平時維持良好姿勢（站姿、走路、坐姿、睡姿）；搬運重物前應暖身、不可過度彎曲身體、應採蹲踞姿勢、物品盡量靠近身體、避免重複或過度扭轉，背部保持一直線；手部避免保持同一姿勢過長，適時使用手工具代替人力作業。

職業安全衛生設施規則第324條之2（異常工作負荷促發疾病預防）：雇主使勞工從事輪班、夜間工作、長時間工作等作業，為避免勞工因異常工作負荷促發疾病，應訂定異常工作負荷促發疾病預防計畫，採取下列措施並留存執行紀錄：
  1. 辨識及評估高風險群
  2. 安排醫師面談及健康指導
  3. 調整或縮短工作時間及更換工作內容之措施
  4. 實施健康檢查、管理及促進
  5. 執行成效之評估及改善
  6. 其他有關安全衛生事項
依規定免配置醫護人員者，得以執行紀錄或文件代替。

過勞（異常工作負荷）判定指引

所稱長時間工作，指近6個月內每個月的加班時數。對異常工作負荷之判定：

  1. 異常事件：發病前一天是否持續工作或遭遇嚴重異常事件（精神負荷、身體負荷、工作環境變化事件）
  2. 短期工作過重：評估發病前約1週內是否常態性長時間勞動
  3. 長期工作過重：
    • 發病前1個月加班時數超過100小時【極相關】
    • 發病前2至6個月平均每月超過80小時【極相關】
    • 發病前1至6個月平均加班小於45小時【關聯性薄弱】
（依據：職業促發腦血管及心臟疾病之認定參考指引）

心血管疾病

常見原因為動脈粥狀硬化導致血管阻塞引發血流不順，症狀有心悸、呼吸困難、紫紺、眩暈、暈厥等。常見心血管疾病包括冠狀動脈心臟病、中風、心臟衰竭、心律不整、瓣膜性心臟病。危險因子：三高、肥胖、抽菸、睡眠不足、缺乏運動、不健康飲食、壓力、高工時。

職業安全衛生法 第6條第2項（重申）：雇主應妥為規劃及採取安全衛生措施：①重複性作業促發肌肉骨骼疾病之預防 ②異常工作負荷促發疾病之預防 ③執行職務因他人行為遭受身體或精神不法侵害之預防，並建立申訴、調查及處理程序 ④避難、急救、休息或其他保護勞工身心健康之事項。罰則：3萬～75萬元罰鍰（致發生職業病者處5萬～300萬）。
職業安全衛生設施規則第324條之3（執行職務遭受不法侵害預防）：雇主為預防勞工於工作場所執行職務因他人行為致遭受身體或精神上不法侵害，應訂定執行職務遭受不法侵害預防計畫，採取下列措施並留存執行紀錄：
  1. 辨識及評估危害
  2. 適當配置作業場所
  3. 依工作適性適當調整人力
  4. 建構行為規範
  5. 辦理危害預防及溝通技巧訓練
  6. 建立事件之處理程序
  7. 執行成效之評估及改善
  8. 其他有關安全衛生事項
事業單位勞工人數達100人以上者應訂定並執行；未達100人者得以執行紀錄或文件代替。（勞動部依此規定於111年8月訂定公告「執行職務遭受不法侵害預防指引(第三版)」）

職場暴力與霸凌

職場暴力：工作者因執行職務遭受內部或外部人員對其身體或精神之不法侵害（包括攻擊、脅迫、霸凌及騷擾等）。

職場霸凌：在工作場所裡，個人或團體對於同事或下屬進行不合理的霸凌行為，包含言語、非言語、身體、心理上的虐待或羞辱。

職場暴力行為態樣：肢體暴力（毆打、抓傷、拳打、腳踢）、心理暴力（威脅、欺凌、騷擾、辱罵）、言語暴力（霸凌、恐嚇、干擾歧視）、性騷擾（不當的性暗示與行為）。

職場暴力預防措施：危害評估、作業場所動線規劃、保全監錄管制、緊急應變、溝通訓練及消除歧視、建構相互尊重之行為規範等。

噪音危害預防

噪音管制法第2條：所稱噪音，指超過管制標準之聲音，其管制對象包括工廠（場）、娛樂場所、營業場所、營建工程、擴音設施及其他。

工作環境中之噪音來源：汽車修理業（機械設備、氣動、電動手工具）；餐飲業（抽油煙機、切剁菜聲）；環境背景噪音。

噪音危害預防措施：選擇低噪音設備、超過90分貝採取工程控制、配戴有效之耳塞或耳罩、工作方法改善、工作者進行噪音危害之健康檢查。噪音預防策略也包括拉遠距離、減噪（包覆/隔振）、確實配戴防護具。
