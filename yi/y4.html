一、急救基本概念

1. 急救的定義

急救是對於遭受意外傷害或突發疾病的傷患，在緊急醫療救護人員未達現場或送至醫院治療前，給予立即的救護。

2. 急救的目的（考試常考四項）

目的說明
挽救生命維持生命徵象，避免死亡
防止傷勢或病情惡化避免二次傷害
促進康復減輕痛苦，加速復原
及早送醫，增進醫療效果爭取治療時效
記憶口訣：挽、防、促、送

二、急救相關法規（不要遲疑，請伸出你的救援之手）

法規條文重點
民法第150條因避免自己或他人生命、身體、自由或財產上急迫之危險所為之行為，不負損害賠償之責。
刑法第24條因避免自己或他人生命、身體、自由、財產之緊急危難而出於不得已之行為，不罰。
醫師法第28條臨時施行急救者，不罰。
緊急醫療救護法第14條之2非醫護人員基於必要使用AED等緊急救護設備救人「除罪化」。
考試重點：這四條法規是「善良管理人/好撒馬利亞人條款」的法源，題目常考「哪一法規讓非醫護人員用AED不受處罰」→答案是緊急醫療救護法第14條之2。

三、黃金3分鐘與生存之鏈

1. 黃金3分鐘 / 腦部缺氧

  • 心跳呼吸停止後，3分鐘內即可能因腦部缺氧而受損。
  • 超過10分鐘可能導致腦死，心肺功能隨之喪失。
  • 心跳停止後，每過1分鐘，存活率下降7%~10%；若適時處置（CPR），下降幅度可減半。
  • 另一版本說法：腦部缺氧4-6分鐘即可能腦死。

2. CPR 與輸送血液效果（考題常考數字）

心臟狀態血流輸送效果
心臟自己跳100%
心臟不跳0%
施行CPR20-25%（已足夠腦部使用）

3. 生存之鏈（AHA ECC 成人生存之鏈，5環節）

  1. 立即確認心臟停止，並啟動緊急應變系統（儘早求救）
  2. 儘早CPR，並強調先作胸部按壓
  3. 進行快速去顫（AED）
  4. 有效高級救命術
  5. 整合的心臟停止後照護

4. 「3分鐘內的貴人」是誰？

答案：一般民眾（家人、朋友、鄰居或路人）——因為救護技術員、醫護人員通常無法在3分鐘內到場。

四、心肺復甦術 CPR

1. CPR 的定義與適應症

定義：結合人工呼吸與心外按摩二種技術，對生命危急之病患所採取的急救方式。

適應症：心臟病突發、窒息、觸電、過敏反應、藥物中毒、氣喘發作、異物梗塞、溺水、中風、中毒等原因引起之呼吸或/及心臟搏動停止。

施做對象：昏迷、不會動、沒有（正常）呼吸之患者。

2. 2010年版CPR重大變革

  • 順序由 A-B-C 改為「叫叫C-A-B」：先胸部按壓，再開呼吸道，再檢查呼吸。
  • 按壓速率至少每分鐘100次（100-120次/分）
  • 成人按壓深度至少約5公分
  • 按壓與呼吸比例30:2，直到AED準備就緒

3. 成人CPR口訣（叫叫CABD）

步驟內容細節
叫①確認反應、呼吸雙手用力拍打肩膀、喊叫「先生/小姐你怎麼了」，確認昏迷、沒有呼吸或不正常呼吸（檢查不超過10秒）
叫②求救打119、取得AED；若無旁人則自行撥打119並立刻CPR
C胸部按壓 Chest compression兩乳頭連線中央（胸骨下半段），深度至少5公分，速率100-120次/分，按壓30次
A暢通呼吸道 Airway壓額抬下巴
B人工呼吸 Breathing捏鼻、口對口(或面罩)吹氣2次，每次約1-2秒鐘，看到胸部起伏即可
D使用AED Defibrillation依語音指示操作

4. 胸部按壓細節

  • 位置：兩乳頭連線中點的胸骨上（胸骨下半段）
  • 手勢：一手掌根定位，另一手疊於其上，十指交叉互扣翹起，以掌根施力
  • 姿勢：手肘（肘關節）打直不可彎曲，以體關節為支點，用身體重量垂直下壓
  • 深度：至少5公分（4-5cm）
  • 速率：至少100次/分（100-120次/分），讀數：一下、二下…三十
  • 比例：壓30下、吹2口氣（30:2）
  • 口訣：用力壓．快快壓．胸回彈．莫中斷
  • 另一口訣：兩乳連線壓胸骨，每秒2下用力壓，壓胸回彈莫中斷
  • 放鬆時掌根不可離開胸骨，且不可用力

5. 小兒、嬰兒按壓位置（易混淆考點）

對象按壓位置
小兒胸骨與兩乳頭連線交會處
嬰兒兩乳頭連線中線下方

6. CPR的ABC三步驟意義

代號英文中文動作
AAirway保持呼吸道通暢打開呼吸道，清除口腔異物
BBreathing恢復呼吸功能施行人工呼吸
CCirculation恢復循環功能施行心外按摩

7. 再評估生命徵象

四個CPR週期吹氣後（約一分鐘後）：

  • 沒有循環徵象 → 繼續CPR
  • 有循環徵象但沒有呼吸 → 人工呼吸
  • 有循環徵象、有呼吸、無意識 → 檢查身體，採復甦姿勢
  • 有循環徵象、有呼吸、有意識 → 檢查身體

8. 何時停止CPR？（考試重點）

  • 做到119救護車人員趕到時
  • 做到病人恢復生命徵象時
  • 當AED正在判讀是否該電擊時（此時暫停按壓，但非隨便停止）
⚠️ 千萬不要隨便停止CPR！

9. CPR常見錯誤

  • 氣吹不進去
  • 胸部按壓位置不對
  • 胸部按壓方式不對
  • 胸部按壓深度不對
  • 胸部按壓速率過慢或過快

五、AED 自動體外電擊器

1. AED定義與功能

AED = 自動體外去顫器（Automated External Defibrillator），俗稱「傻瓜電擊器」。

  • 能自動偵測患者心律，分析是否可用電擊治療
  • 對心搏異常患者施以電擊，使心臟重新啟動、恢復正常頻率
  • 操作簡易、輕便且具語音提示，只要經基本訓練，一般民眾、基礎救護人員均可使用

2. 何處可找到AED？

救護車、各大公共場所（醫院、車站等）。

3. AED操作四步驟

  1. 開電源：按下開關鍵
  2. 貼電擊片：
    • 右側電擊片：置於胸骨右上緣、鎖骨下方
    • 左側電擊片：置於左乳頭左下外側（電擊片上緣距左腋窩下約10-15公分）
  3. 插入電擊片導線
  4. 分析心律並依指示給予電擊

4. AED安全操作三重點（考試常考）

  • 分析心律及電擊時，均不可接觸或碰觸病人
  • 電擊前警告所有人：「我離開」－「你離開」－「大家都離開」
  • 檢視確定無人接觸患者，再按下電擊鈕

5. AED救活率數據

  • 研究顯示3至5分鐘內施給CPR及電擊，可使救活率提升至49%~75%
  • 消防局統計：即時電擊使傷患恢復生命徵象成功機率趨近12%

6. 心肺復甦術程序整體流程（叫叫CABD口訣圖）

  1. 確認病患意識及呼吸
  2. 緊急求救並取出AED備用
  3. 進行心外按壓
  4. 暢通呼吸道
  5. 進行人工呼吸
  6. 使用AED進行急救

七、燒燙傷與化學灼傷處理

1. 燒傷的種類

種類原因
乾燒傷瓦斯爆炸、火災、接觸性/摩擦性灼傷
燙傷熱蒸氣、熱水
冷燒傷接觸冰凍金屬、凝固氣體，如液氮(-196°C)
化學燒傷清潔劑、硫酸、鹽酸、硝酸等強酸強鹼
電燒傷閃電、高壓電
放射燒傷紅外線、紫外線、X射線

2. 燒傷程度分級（重要考點）

等級特徵
第一度紅、腫、痛，傷及表皮淺層
淺二度紅、痛、水泡，傷到表皮
深二度長時間燙傷、燒傷，呈白或紅色，較不痛，皮膚尚柔軟
第三度皮膚呈白或黑色，乾硬如皮革狀，可能深及皮下脂肪、肌肉或骨骼

3. 燒燙傷處理口訣「沖脫泡蓋送」

步驟內容
沖清水沖洗至少三十分鐘
脫以剪刀除去束縛衣物（避免硬扯造成二次傷害）
泡等待送醫前繼續泡水
蓋蓋上清潔布料或紗布
送立即送急診緊急處置

4. 輕微燒燙傷處理注意事項

  • 解除束縛物，把傷處沖或浸於冷水，直到不痛為止
  • 不可塗油膏、油脂類塗劑
  • 如起水泡，用消毒紗布蓋住，不可刺破水泡

5. 嚴重燒燙傷處理注意事項

  • 檢查或維持傷者呼吸道通暢
  • 不可企圖移去傷者的傷處或用冷水沖傷口（大面積嚴重燒傷避免失溫）
  • 用消毒過的厚紗布保護傷口
  • 讓患者躺下預防休克
  • 可將受傷部位墊高，減輕腫脹
  • 快速送醫

6. 化學濺觸急救須知（酸鹼類化學藥品濺到皮膚/眼睛）

  • 最佳方法：60秒內立即使用酸鹼中和噴霧（敵腐靈）噴至濺傷部位（不需沖水），用完整瓶沖洗劑，立刻送醫。
  • 次要方法（無沖洗劑時）：60秒內立即用水大量沖洗濺傷部位15分鐘以上，直到皮膚顏色恢復正常為止，並立刻送醫。

八、中毒處理

1. 中毒處理注意事項

  • 勿任意催吐
  • 不可酸鹼中和
  • 皮膚接觸中毒，用清水清洗
  • 脫除含毒之衣物
  • 吸入中毒時，將患者置於空氣流通處
  • 將疑似毒物帶給醫療人員

2. 中毒緊急處理步驟

連絡毒物中心－02-28717121（榮總）或醫療單位，並告知：

  • 確定患者意識狀態
  • 毒物名稱
  • 吞下毒物的量和時間
  • 估計送醫所需時間
  • 聽從醫療人員指導
  • 儘速將病患搬離污染現場

3. 腐蝕性毒物中毒（眼睛）處理

  • 以流動清水沖洗（將眼瞼打開）
  • 自眼角內向外，持續15分鐘以上
  • 至眼科就診

九、火災與滅火

1. 燃燒四要素

燃燒三要素為：可燃物、助燃物（氧）、熱能（溫度）。燃燒四要素再加上第四項：

  1. 可燃物
  2. 氧（助燃物）
  3. 熱能（溫度）
  4. 連鎖反應

2. 滅火的基本法（對應燃燒要件）

燃燒條件滅火方法滅火原理實例
可燃物隔離法搬離或除去可燃物移走木材紙張、設防火巷/牆/門、關閉進料口
助燃物窒息法除去助燃物（降低氧氣濃度）鍋蓋覆蓋、泡沫覆蓋油槽、CO2/水蒸氣置換氧氣
能量（熱能）冷卻法減少熱能撒水冷卻、釋放高壓二氧化碳（氣體冷卻）
連鎖反應抑制法中斷連鎖反應使用乾粉滅火劑等抑制自由基連鎖反應

3. 火災分類（ABCD類，考試最愛考）

類別名稱可燃物滅火方法
A類普通火災木製品、紙纖維、棉布、橡膠、塑膠等水或含水溶液冷卻降溫
B類油類火災石油、可燃性氣體(乙烷、乙炔)、可燃油脂掩蓋隔離氧氣（窒息）
C類電氣火災通電中電器、變壓器、電線、配電盤不導電滅火劑，宜先截斷電源再依A或B類處理
D類金屬火災活性金屬如鎂、鉀、鋰、鋯、鈦等特定金屬滅火劑（燃燒溫度甚高）

4. 滅火器種類與適用

滅火器適用火災類別
二氧化碳滅火器B、C類火災
乾粉滅火器B、C類火災
ABC乾粉滅火器A、B、C類火災（最通用）

5. 滅火器操作方法（拉、瞄、壓、掃）

步驟內容
拉拉開安全插梢
瞄拉皮管，朝向火源根部
壓用力壓下手壓柄
掃左右移動掃射

6. 滅火器操作注意事項

  • 確認火災類別性質，取用合適滅火器
  • 室外使用應立於上風處（由煙方向判定）；室內使用應預留逃生方向
  • 勿朝向濃煙及人噴射
  • 放射後無法長久保存，建議重新充填藥劑
  • 滅火後仍需用水澆濕，確認火勢熄滅防止再燃

7. 火災緊急應變流程

通報 → 初期滅火 → 避難逃生

8. 避難逃生原則

  • 市售蓄壓式20型乾粉滅火器放射時間約12至15秒，時間不長
  • 火勢擴大無法撲滅時，切莫執著搶救財物，應立即避難逃生
  • 平時應訓練員工熟習避難路線，確保兩方向避難出口位置
  • 留意避難指標：出口標示燈、避難方向指示燈、緊急照明燈
  • 避難路線勿堆放雜物

十、傷患搬運法

  • 單人搬運
  • 雙人搬運（四手座法）
  • 四手座疊法
  • 擔架搬運
